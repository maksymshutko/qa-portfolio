## 🚀 Quick Start

### Prerequisites
- Python 3.7+
- Robot Framework

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/maksymshutko/qa-portfolio.git
   cd qa-portfolio
   ```

2. Install dependencies:
   ```bash
   pip install robotframework robotframework-seleniumlibrary robotframework-requests
   ```

3. Run tests:
   ```bash
   robot robot-tests/
   ```
